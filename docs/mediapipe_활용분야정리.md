# MediaPipe 모델 활용 분야 정리

MediaPipe는 이미지, 영상, 음성, 텍스트를 기기 안에서 처리할 수 있도록 사전 학습 모델과 추론 파이프라인을 제공한다. 웹캠 프레임처럼 연속으로 들어오는 데이터도 처리할 수 있어 실시간 인터랙션, 자세 분석, 객체 인식 등의 기능을 구현하기 좋다.

이 문서는 MediaPipe Tasks API를 기준으로 각 모델이 어떤 결과를 만들고, 그 결과로 어떤 문제를 해결할 수 있는지 정리한다.

## 한눈에 고르기

| 해결하려는 문제 | 우선 검토할 Task | 주요 출력 |
|---|---|---|
| 화면에서 얼굴 위치 찾기 | Face Detector | 얼굴 영역, 얼굴 주요점 |
| 표정·시선·얼굴 방향 분석 | Face Landmarker | 얼굴 랜드마크, 블렌드셰이프, 변환 행렬 |
| 손가락 위치와 움직임 추적 | Hand Landmarker | 손 관절 좌표, 왼손·오른손 정보 |
| 정해진 손동작 인식 | Gesture Recognizer | 손 랜드마크, 제스처 분류 결과 |
| 전신 자세와 운동 동작 분석 | Pose Landmarker | 신체 관절 좌표, 선택적 분할 마스크 |
| 얼굴·손·몸을 함께 추적 | Holistic Landmarker | 얼굴, 양손, 전신 랜드마크 |
| 물체의 종류와 위치 찾기 | Object Detector | 클래스, 신뢰도, 경계 상자 |
| 이미지 전체의 종류 판단 | Image Classifier | 이미지 클래스와 신뢰도 |
| 사람·배경·사물 영역 분리 | Image Segmenter | 픽셀 단위 클래스/신뢰도 마스크 |
| 사용자가 지정한 물체 영역 분리 | Interactive Segmenter | 관심 지점 또는 영역 기반 마스크 |
| 비슷한 이미지 검색 | Image Embedder | 이미지 특징 벡터, 유사도 |
| 음향 이벤트 판별 | Audio Classifier | 소리 클래스와 신뢰도 |
| 문장의 분류·언어 판별·유사도 계산 | Text Tasks | 클래스, 언어, 텍스트 특징 벡터 |

## 1. 얼굴 관련 모델

### Face Detector

이미지나 영상에서 얼굴이 있는 위치를 찾는다. 얼굴 영역을 나타내는 경계 상자와 눈, 코, 입 주변의 주요점을 반환한다.

해결할 수 있는 문제:

- 영상 통화에서 얼굴을 중심으로 자동 크롭
- 카메라 앞 사람의 존재 여부 확인
- 사진 속 얼굴 수 집계
- 얼굴 영역에 모자이크나 스티커 적용
- Face Landmarker 실행 전 얼굴 후보 영역 검출

한계와 주의:

- 얼굴이 누구인지 식별하는 모델은 아니다.
- 마스크 착용, 심한 측면 얼굴, 작은 얼굴, 강한 역광에서는 정확도가 낮아질 수 있다.
- 출입 통제 같은 신원 확인 기능에는 별도의 얼굴 임베딩 모델과 보안 설계가 필요하다.

### Face Landmarker

얼굴의 세밀한 3차원 랜드마크를 추정한다. 설정에 따라 표정 계수인 블렌드셰이프와 얼굴 변환 행렬도 얻을 수 있다.

해결할 수 있는 문제:

- 눈 깜빡임, 입 벌림, 미소 등 표정 상태 추정
- 얼굴 방향과 고개 움직임 분석
- 아바타와 VTuber 캐릭터의 표정 구동
- 안경, 마스크, 화장 효과를 얼굴에 정렬하는 AR 기능
- 화면 집중도나 졸음 징후를 보조적으로 감지

한계와 주의:

- 감정은 표정만으로 확정하기 어렵다. 블렌드셰이프는 얼굴 근육 형태에 가까운 신호로 다뤄야 한다.
- 시선 방향은 눈과 얼굴 랜드마크를 이용해 추가 계산해야 하며 전용 시선 추적 장비 수준의 정밀도를 기대하기 어렵다.
- 졸음, 건강 상태, 감정과 관련된 판단은 오탐 가능성을 포함해 보조 지표로 사용한다.

## 2. 손과 제스처 모델

### Hand Landmarker

손마다 21개 관절 랜드마크와 왼손·오른손 정보를 반환한다. 이미지 좌표와 3차원 월드 좌표를 이용해 손가락의 상대적인 위치와 움직임을 계산할 수 있다.

해결할 수 있는 문제:

- 손가락으로 화면 포인터 이동
- 핀치, 집기, 펼치기 같은 동작 감지
- 가상 악기, 드로잉, 프레젠테이션 제어
- 손가락 관절 가동 범위 측정
- 수어 인식을 위한 손 특징 추출
- 제조·조립 작업에서 손동작 순서 분석

한계와 주의:

- 손이 겹치거나 화면 밖으로 일부 벗어나면 관절 추적이 불안정해질 수 있다.
- 깊이 카메라 없이 얻는 3차원 좌표는 실제 거리 측정값으로 바로 사용하기 어렵다.
- 수어는 손 모양 외에도 움직임, 방향, 얼굴 표정, 문맥이 중요하므로 Hand Landmarker 하나로 전체 언어를 해석하기는 어렵다.

### Gesture Recognizer

손 랜드마크 추정과 손동작 분류를 한 파이프라인에서 수행한다. 기본 제스처를 사용하거나 목적에 맞는 사용자 정의 제스처 모델을 연결할 수 있다.

해결할 수 있는 문제:

- 엄지 올리기, 브이, 손바닥 등의 명령 입력
- 키오스크와 전시물의 비접촉 제어
- 회의·방송 프로그램의 단축 동작
- 게임과 AR 콘텐츠의 제스처 인터페이스
- 반복되는 작업 신호 자동 기록

설계 팁:

- 단일 프레임의 손 모양은 Gesture Recognizer가 잘 맞는다.
- 좌우 이동이나 원 그리기처럼 시간 변화가 핵심인 동작은 여러 프레임의 랜드마크를 저장해 별도의 시계열 규칙 또는 모델로 판단한다.

## 3. 자세와 전신 모델

### Pose Landmarker

머리, 어깨, 팔, 골반, 다리 등 33개 신체 랜드마크를 추정한다. 이미지 좌표와 3차원 월드 좌표를 제공하며, 설정에 따라 사람 영역 분할 마스크도 출력할 수 있다.

해결할 수 있는 문제:

- 스쿼트, 런지, 팔굽혀펴기 횟수 계산
- 관절 각도를 이용한 운동 자세 피드백
- 요가 동작 분류와 자세 유지 시간 측정
- 재활 운동의 동작 범위 기록
- 게임 캐릭터와 아바타의 전신 제어
- 작업자의 불편한 자세나 반복 동작 탐지
- 스포츠 영상에서 폼 비교

한계와 주의:

- 관절 각도는 랜드마크로부터 계산해야 한다.
- 카메라 방향, 렌즈 왜곡, 신체 가림, 헐렁한 옷이 결과에 영향을 준다.
- 의료 진단이나 부상 판정에 직접 사용하려면 임상 검증과 전문가 검토가 필요하다.
- 정확한 거리와 관절 위치가 필요하면 카메라 보정 또는 깊이 센서를 함께 고려한다.

### Holistic Landmarker

얼굴, 양손, 전신 자세를 한 사람 단위로 함께 추적한다. 몸 전체의 비언어적 표현을 다뤄야 할 때 유용하다.

해결할 수 있는 문제:

- 전신 아바타와 캐릭터 모션 캡처
- 수어 인식을 위한 손·얼굴·상체 특징 결합
- 발표자의 자세, 손동작, 표정 분석
- 댄스와 퍼포먼스 동작 기록
- 사람과 로봇 사이의 자연스러운 동작 인터페이스

한계와 주의:

- 여러 종류의 랜드마크를 동시에 계산하므로 단일 Task보다 처리 비용이 커질 수 있다.
- 결과를 실제 서비스 판단에 사용하려면 프레임 간 흔들림 완화, 누락 처리, 동작 구간 분리 로직이 추가로 필요하다.

## 4. 객체와 이미지 이해 모델

### Object Detector

이미지 안에 있는 객체의 종류, 신뢰도, 위치를 경계 상자로 반환한다. 이미지 한 장에 여러 객체가 있을 때 각각의 위치가 필요하면 적합하다.

해결할 수 있는 문제:

- 사람, 차량, 동물, 생활용품 등의 실시간 검출
- 매장 진열 상태와 특정 물품 존재 여부 확인
- 작업 구역의 안전모나 도구 확인
- 로봇이 집을 물체의 후보 위치 탐색
- 영상 속 객체 수 집계와 이동 경로 분석의 첫 단계

한계와 주의:

- 기본 모델이 학습한 클래스만 인식한다. 프로젝트 고유 물체는 데이터 수집과 사용자 정의 모델 학습이 필요하다.
- 경계 상자는 물체의 정확한 윤곽을 나타내지 않는다. 윤곽이 필요하면 분할 모델을 사용한다.
- 객체 추적 ID는 별도 추적 로직을 통해 프레임 사이에서 연결해야 한다.

### Image Classifier

이미지 전체를 대표하는 클래스를 예측한다. 객체 위치보다 장면이나 이미지의 대표 속성이 중요할 때 사용한다.

해결할 수 있는 문제:

- 음식, 식물, 제품 종류 분류
- 정상·불량 이미지 분류
- 실내·실외, 낮·밤 같은 장면 분류
- 사진 자동 태깅과 콘텐츠 필터링
- 카메라 입력 상태 또는 작업 단계 분류

Object Detector와의 선택 기준:

- 이미지 전체에 하나의 대표 라벨이 필요하면 Image Classifier를 선택한다.
- 여러 물체의 종류와 위치가 필요하면 Object Detector를 선택한다.

### Image Segmenter

이미지의 각 픽셀이 어느 클래스에 속하는지 추정한다. 객체의 정확한 영역이나 배경 분리가 필요한 문제에 적합하다.

해결할 수 있는 문제:

- 화상 회의의 배경 흐림과 배경 교체
- 사람, 머리카락, 의류 영역 분리
- 도로, 차량, 보행자 영역 분석
- 제품이나 결함의 면적 측정
- AR 효과를 특정 영역 뒤나 앞에 자연스럽게 배치

한계와 주의:

- 얇은 물체, 머리카락, 경계가 흐린 영역에서는 마스크 품질이 떨어질 수 있다.
- 실제 길이나 면적을 구하려면 카메라 보정과 기준 크기가 필요하다.

### Interactive Segmenter

사용자가 클릭한 지점이나 지정한 관심 영역을 기준으로 대상 물체의 마스크를 생성한다.

해결할 수 있는 문제:

- 사진 편집기의 원클릭 배경 제거
- 사용자가 고른 물체만 색상이나 효과 변경
- 데이터 라벨링 도구의 반자동 마스크 생성
- 의료·산업 이미지에서 관심 영역 선택 보조

### Image Embedder

이미지를 의미적 특징을 담은 숫자 벡터로 변환한다. 두 이미지의 유사도를 비교하거나 가까운 이미지를 검색할 수 있다.

해결할 수 있는 문제:

- 비슷한 상품과 사진 검색
- 중복 또는 유사 이미지 탐지
- 기준 이미지와 가장 가까운 샘플 찾기
- 소량의 예시를 이용한 간단한 분류
- 이미지 군집화와 이상 이미지 후보 탐색

한계와 주의:

- 임베딩의 유사도는 업무에서 정의한 동일성 기준과 다를 수 있다.
- 얼굴 임베딩 전용 모델이 아니므로 신원 확인 목적으로 바로 사용하면 안 된다.

## 5. 오디오와 텍스트 모델

MediaPipe는 영상 외에도 Audio 및 Text Tasks API를 제공한다. Python API에서 대표적으로 다음 Task를 사용할 수 있다.

### Audio Classifier

오디오 구간을 소리 클래스로 분류한다.

활용 예:

- 박수, 노크, 사이렌, 기계음 등의 이벤트 감지
- 주변 환경 소리 분류
- 음성 존재 여부나 특정 음향 패턴 확인
- 설비 소리 기반 이상 징후 탐색

정확한 음성 내용을 문자로 바꾸는 기능은 음성 인식 모델의 영역이다. Audio Classifier는 소리의 종류를 판단하는 문제에 적합하다.

### Language Detector

입력 문장이 어떤 언어로 작성되었는지 예측한다.

활용 예:

- 다국어 문의 자동 분류
- 번역할 언어 자동 선택
- 언어별 검색 인덱스와 처리 파이프라인 분기

### Text Classifier

텍스트를 미리 정의한 범주로 분류한다.

활용 예:

- 문의 유형, 주제, 의도 분류
- 긍정·부정과 같은 감성 분류
- 스팸 또는 유해 콘텐츠 후보 탐지
- 문서 자동 태깅

### Text Embedder

문장을 의미 벡터로 변환해 텍스트 사이의 유사도를 계산한다.

활용 예:

- 의미 기반 문서 검색
- 비슷한 질문과 FAQ 연결
- 중복 문의 탐지
- 문장 군집화와 추천

## 6. 복합 문제 구성 예시

실제 문제는 하나의 모델보다 여러 Task와 후처리를 연결해 해결하는 경우가 많다.

### 홈트레이닝 자세 코치

1. Pose Landmarker로 관절 좌표를 얻는다.
2. 팔꿈치, 무릎, 골반 각도를 계산한다.
3. 프레임별 상태를 시계열로 저장한다.
4. 동작 단계를 구분해 반복 횟수를 센다.
5. 허용 범위를 벗어나면 자세 교정 메시지를 표시한다.

### 손동작 프레젠테이션 리모컨

1. Gesture Recognizer로 손 모양을 분류한다.
2. 같은 제스처가 일정 시간 유지됐는지 확인한다.
3. 연속 입력을 막기 위해 쿨다운 시간을 둔다.
4. 다음 슬라이드, 이전 슬라이드, 포인터 표시 명령으로 연결한다.

### 웹캠 기반 집중 상태 보조 분석

1. Face Detector로 얼굴 존재 여부를 확인한다.
2. Face Landmarker로 눈, 입, 고개 방향 관련 특징을 계산한다.
3. 일정 시간 구간의 평균과 변화량을 사용한다.
4. 조명 변화와 일시적인 검출 실패를 필터링한다.
5. 결과는 참고용 상태 지표로 표시한다.

### 작업장 안전 모니터링

1. Object Detector로 사람과 안전 장비 후보를 검출한다.
2. Pose Landmarker로 위험 자세를 분석한다.
3. 객체 위치와 사람 위치의 관계를 계산한다.
4. 여러 프레임에서 조건이 지속될 때 경고한다.
5. 현장 환경으로 수집한 데이터로 정확도를 별도 검증한다.

## 7. 모델 선택 시 확인할 기준

- **필요한 결과 형태:** 클래스, 경계 상자, 랜드마크, 마스크, 임베딩 중 어떤 출력이 필요한지 정한다.
- **입력 방식:** 정지 이미지, 저장된 영상, 실시간 웹캠 중 실행 모드를 선택한다.
- **처리 속도:** 해상도, 검출 대상 수, 모델 크기, CPU/GPU 사용 여부를 함께 조정한다.
- **대상 환경:** 카메라 각도, 조명, 배경, 사람 간 가림이 실제 사용 환경과 비슷한지 확인한다.
- **시간 정보:** 순간 자세와 일정 시간 동안 이어지는 동작을 구분한다. 동작 문제에는 프레임 누적과 상태 관리가 필요하다.
- **사용자 정의 필요성:** 기본 모델의 클래스와 제스처로 해결되지 않으면 목적에 맞는 모델을 학습해 Task에 연결한다.
- **평가 지표:** 정확도만 확인하지 말고 누락, 오탐, 처리 지연, 사용자별 편차도 측정한다.
- **개인정보와 안전:** 얼굴, 신체, 음성 데이터의 저장 범위와 보관 기간을 정하고 사용자 동의를 받는다.

## 8. 이 프로젝트에서 시작하기 좋은 순서

1. OpenCV로 웹캠 프레임을 정상적으로 읽는지 확인한다.
2. Hand Landmarker 또는 Pose Landmarker 하나를 선택해 랜드마크를 화면에 그린다.
3. 랜드마크 좌표로 거리나 각도 같은 간단한 특징을 계산한다.
4. 임계값과 상태 전이를 이용해 한 가지 동작을 판별한다.
5. 조명, 거리, 사용자, 카메라 각도를 바꿔 오탐 사례를 수집한다.
6. 필요할 때 Gesture Recognizer, Holistic Landmarker 또는 사용자 정의 모델로 확장한다.
